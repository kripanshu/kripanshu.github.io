# kripanshu.github.io

Personal portfolio. Terminal-themed, built with [Astro](https://astro.build).

## Develop

```bash
npm install
npm run dev    # http://localhost:4321
```

## Build

```bash
npm run build  # outputs to dist/
npm run preview
```

## Deploy

Pushes to `main` trigger the GitHub Pages workflow (added in a later commit).
